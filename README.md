# Nexro Digital Portfolio

A responsive static portfolio website for **Nexro Digital** by Imesh V. Chandrasiri.

## Included
- `index.html` — portfolio sections and page content
- `style.css` — responsive dark navy / cyan / orange design
- `script.js` — mobile navigation, reveal-on-scroll, year and back-to-top
- `assets/nexro-mark.svg` — original vector logo mark

## Preview locally
Open `index.html` in a browser. For a local server, from this folder run:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.

## Free hosting
### GitHub Pages
1. Create a repository on GitHub (for example `nexro-digital-portfolio`).
2. Upload all files/folders in this package to the repository root.
3. Open repository **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for the published URL shown in the Pages settings.

### Netlify
1. Sign in to Netlify.
2. Drag the extracted website folder into the manual deploy area (or connect the GitHub repository).
3. Netlify provides a public URL.

- Add a real portrait if you want a personal photo in About.
